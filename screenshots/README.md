# Screenshots

Place terminal screenshots here. Recommended formats:

- `terminal-default.png` — default theme
- `ghost-glass.png` — ghost-glass theme with transparency
- `amber-crt.png` — amber CRT theme with glow and scanlines
- `hyprland.png` — Hyprland tiling mode
- `sixel.png` — inline Sixel image rendering
- `search.png` — scrollback search overlay
- `splits.png` — window splits
- `metal.png` — Metal GPU rendering in action
