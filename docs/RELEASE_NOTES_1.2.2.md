# Termatica 1.2.2

## Icon

- Lightens the app icon and GitHub repository logo from a pure black
  background to a grey background, so it reads as grey and white. Rounded
  corners are retained across the Dock icon (`AppIcon.icns`), `AppIcon.png`,
  `AppIcon-1024.png`, `AppIcon-source.png`, and the embedded `AppIcon.svg`.

## Scope

- Icon-only release. No source, configuration, theme, or behavior changes.
