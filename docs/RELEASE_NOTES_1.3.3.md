- Completely removed all benchmarking functionality: the `bench` command,
  `t b`, the `termyx engine bench` helper app, the `--termyx-bench` mode,
  and all related source files. No benchmark code remains.

  anchoring, option keybindings, grey app icon, black GitHub logo, etc.).
