# Metal Phase 9 field qualification

Termatica 1.11.0 adds factual, privacy-safe field qualification for the optional
Metal renderer. AppKit remains the default.

## Commands

`t rr` now emits renderer-report schema 4. `t rq` prints the smaller
qualification view. Both describe only evidence observed by the currently
running Termatica process.

The report includes:

- native process architecture and Rosetta translation state;
- current, minimum, and maximum observed display count;
- observed scale and refresh-rate diversity;
- display-parameter and display-count-change events;
- system wake and screen-wake events;
- per-pane display index and per-reason presentation recovery counts;
- Metal health, quarantine, failure, and retry counters;
- an explicit list of gates that remain open.

It excludes display names, terminal content, commands, working directories,
environment variables, and config paths.

## Qualification boundary

The current-session report cannot combine evidence from different Macs. A run
on Apple Silicon does not pass the Intel-native gate, and an Intel run does not
pass the Apple-Silicon-native gate. A one-display session does not pass the
multi-display gate. A notification generated by a test is not physical visual
inspection. Synthetic evidence is never accepted for a default-renderer change.

The deterministic Phase 9 test validates the accounting and rejection rules;
it does not claim to have physically hot-plugged a monitor, slept a Mac, moved a
window between real displays, or visually inspected pixels. Those remain field
operations on representative hardware.

## Deterministic release gate

`--phase9-field-self-test` exercises AppKit and Metal where available, two
panes, repeated screen and backing-scale recovery, wake paths, Unicode and
complex grapheme preservation, schema-4 privacy, and synthetic-proof rejection.

AppKit remains the default while any field gate is open.

## Release-candidate evidence

- Complete `make check`: pass, including native Metal parity, switching,
  scheduling, reliability, Phases 6-9, and the real-PTY compatibility gate.
- AddressSanitizer and UndefinedBehaviorSanitizer: pass for terminal,
  reliability, Phases 6-9, and decoder tests.
- Clang static analyzer: zero diagnostics across all three Objective-C source
  files.
- Five-minute native Metal soak: 12,402 frames, 193.7 MiB processed, 150.8 MiB
  peak footprint against a 256 MiB limit, 5,242,884 cache bytes, one maximum
  in-flight frame, and zero generation reversals.
- Fresh same-machine six-terminal matrix: Termatica led the 15-workload
  geometric mean at 116.5 MB/s, while WezTerm led shell-ready median at
  11.729 ms. See `benchmarks/2026-08-13-v1.11.0-matrix` for every raw result.
